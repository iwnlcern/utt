```python
@dataclass
class KnifePoint:
    board: str; h: str; bx: int; bo: int
    T: Fraction                     # continuous threshold at (board, h)
    discrete: str                   # "X" | "O" | "draw" from the masked discrete oracle
    convention: str                 # prediction of the ratified large-scale convention: winner == h
    agrees: bool                    # discrete == ("X" if h == "X" else "O")
    state_class: str                # "a<b" | "a=b", joined with E(s), e.g. "a=b/E3"
def sweep(N: int) -> list[KnifePoint]
# enumerate every MASKED nonterminal point with bx*q == p_T*M exactly (T = p_T/q, M = bx+bo > 0)
# at starting scale N, using the landed reachable_masks/solve outputs; deterministic order.
def report(scales: list[int], spot_scales: list[int]) -> dict
# runs sweep over exhaustive scales + the targeted spot populations at 64/128 (solve_targeted),
# groups counts by (h, state_class, agrees, discrete), and returns the full disagreement table.
```

- Semantics pinned: the convention under test is P1b — "at exactly representable p = T, the position is treated as won by tie owner h". A knife point AGREES iff the discrete optimal outcome equals h's win; `discrete == "draw"` and `discrete == opponent(h)` are both disagreements, tabulated separately.
- The sweep consumes the LANDED oracles read-only; it never modifies solver code. All comparisons in exact integer/Fraction arithmetic.

from auction_ttt.knife_edge import sweep

def test_equality_enumeration_is_exact():
    # T = 1/2 states admit knife points exactly at bx == bo; verify sweep(4) contains
    # a bx == bo point for a known T = 1/2 state and NO point with bx != bo for it.
    pts = sweep(4)
    half = [p for p in pts if p.T == F(1, 2)]
    assert half and all(p.bx == p.bo for p in half)

def test_sweep_deterministic():
    a = sweep(3); b = sweep(3)
    assert [(p.board, p.h, p.bx, p.bo) for p in a] == [(p.board, p.h, p.bx, p.bo) for p in b]

def test_agreement_field_definition():
    for p in sweep(4):
        assert p.agrees == (p.discrete == p.h)
