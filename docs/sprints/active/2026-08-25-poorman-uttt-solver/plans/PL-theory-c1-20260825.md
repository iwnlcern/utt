from fractions import Fraction
from dataclasses import dataclass

@dataclass(frozen=True)
class Node:
    T: Fraction; r: Fraction          # r = 0 in zugzwang branch (DD C2)
    a: Fraction; b: Fraction          # a = min over X-children, b = max over O-children
    best_x: int; best_o: int          # argmin / argmax cells (conditional best moves)
    zugzwang: bool

def backup(a: Fraction, b: Fraction, h: str) -> tuple[Fraction, Fraction]  # (T, r)
def solve() -> dict[tuple[str, str], Node]        # key (board, h), h in {"X","O"}
def threshold(board: str, h: str, solved) -> Fraction
```

- Key recurrence facts: terminals are T=0 (X line), T=1 (O line), T=1/2 (full, no line).
  For nonterminal `board`: `a = min over empty c of T(apply_move(board,c,"X"), "O")`, `b = max over empty c of T(apply_move(board,c,"O"), "X")` — child h is always `opponent(mover)` (C4), so a and b do not depend on the current h; only the `a > b` branch reads h.
  `backup`: if `a <= b`: `T = b/(1 - a + b)`, `r = (b - a)/(1 - a + b)`; else `T = a if h == "X" else b`, `r = 0`.
- Traversal (PR1): a child has one FEWER empty cell than its parent, so child-first backward induction processes boards in ASCENDING empty-cell count — terminals and E=0/E=1 boards first, the empty root (E=9) last. Every child lookup must assert the child entry is already materialized (regression guard for traversal order).

import numpy as np
OWIN, DRAW, XWIN = 0, 1, 2
class NonDeterminacy(Exception):
    """Pure maximin != pure minimax at a REACHABLE state. HARD STOP (DD C9)."""
def reachable_masks(N: int) -> dict[tuple[str, str], np.ndarray]
# mask[(board, h)][bx, bo] True iff the state is reachable from the scale-N start
# (empty board, budgets (N, N)) via legal bids/payments/moves/h-transitions.
def solve(N: int) -> tuple[dict[tuple[str, str], np.ndarray], dict[tuple[str, str], np.ndarray]]
# (values V, masks): V[(board, h)][bx, bo] in {0,1,2}, (N+1)x(N+1) int8 grids.
def full_matrix_value(board: str, h: str, bx: int, bo: int, V) -> tuple[int, int]
# (pure_maximin, pure_minimax) over the FULL (bid, move) x (bid, move) action matrix — C9a reference.
def solve_targeted(board: str, N: int) -> TargetedResult
# on-demand exact solve at scale N via the PREFIX-PLUS-DESCENDANT path (PR6):
# 1) prefix closure: enumerate every board whose marks are a subset of `board`'s marks
#    (all are nonterminal — a line in a subset would be a line in `board`); forward-propagate
#    the exact reachability masks from (empty, N, N) over that closure only, including the
#    move-1 coin special case; this yields the EXACT mask for every (board, h, bx, bo).
# 2) descendant closure: boards reachable from `board` (marks superset); run the masked
#    fast-path value recursion over that closure only.
# TargetedResult carries .values and .mask for the target (board, h) pairs.
# Hard-fail (raise ValueError) if the target's mask is empty at scale N.
```

- Reachability propagation (PR2, exact forward pass in ascending mark-count): from reachable `(board, h, bx, bo)`, X may win the auction paying any `i` in `1..bx` (choose an O bid `j < i`), or `i = 0` only when `h = "X"` (0–0 tie); child is `(apply_move(board, c, "X"), "O", bx − i, bo)` for every legal `c`. Symmetric for O. Move-1 special (R1): from the empty board either player may move at any payment `0..N` (a tie at any equal bid is resolvable either way by the coin), children get `h' = opponent(mover)`. Terminal boards receive reachability but no value recursion.
- Value recurrence (fast path, ascending empty-count per PR1): per `(board, h)` and grid point `(bx, bo)`:
  `WX[bx', bo'] = max over empty c of V[(apply_move(board,c,"X"), "O")][bx', bo']`,
  `WO[bx', bo'] = min over empty c of V[(apply_move(board,c,"O"), "X")][bx', bo']`.
  Bid-matrix cell (i, j): `i > j → WX[bx−i, bo]`; `j > i → WO[bx, bo−j]`; `i = j → WX[bx−i, bo] if h == "X" else WO[bx, bo−i]`.
  Row-min for bid i: `min(WX[bx−i, bo] if i > 0 else sentinel, prefmin_WO[bx, bo−i−1] if i < bo else sentinel, tie_term(i))` with `prefmin_WO[bx, k] = min(WO[bx, 0..k])`; maximin = max over i. Column-max symmetric via `prefmax_WX[k, bo]`; minimax = min over j. Vectorize with numpy.
  The full Cartesian grid is an internal optimization; `NonDeterminacy` fires ONLY where `mask[bx, bo]` is True. Off-mask inequalities are collected into a diagnostics list on the solution object, never raised (PR2).
- `solve_targeted` sizing: targets are chosen with `E(board) ≤ 5`, so the prefix closure is ≤ 2^(9−E) boards and the descendant closure ≤ 3^E boards — both trivially tractable at N = 64/128. The exact mask comes only from the prefix pass; descendant-only seeding is forbidden (PR6).
