## Global Constraints

- No `engine/` file is created, modified, or deleted (A6; dispatch "Not in scope").
- Compiler flags for every solver target: `-Wall -Wextra -Werror -O3`, `CMAKE_CXX_STANDARD 26`, extensions OFF (§1).
- State identity everywhere is the theory 37-byte serialization: `x[0..8]` uint16 LE at bytes 0..17, `o[0..8]` at 18..35, `forced` (0..8, 9=ANY) at byte 36 (§2; theory §2.2). No hash is ever identity.
- SYMMETRY_ID `d4-lexmin-v1`: the eight destination tables of theory §2.3 verbatim; canon = lexmin of the eight 37-byte serializations as unsigned bytes (§2).
- Claims enum order is fixed: WIN_X=0, WIN_O=1, NOLOSS_X=2, NOLOSS_O=3 (§3, psr-v1 byte 37).
- Only four cross-claim inferences exist: ¬WIN_X ≡ NOLOSS_O, ¬NOLOSS_X ≡ WIN_O, WIN_X ⟹ NOLOSS_X, WIN_O ⟹ NOLOSS_O; disproofs are normalized to complementary proofs before any storage (§3).
- Work threshold K default 1000 expanded nodes, flag `--log-threshold`; root-claim facts bypass K unconditionally (§5 root exemption).
- All persistent integers little-endian; digests are XXH3 (record checksums XXH3-64 seeded 0x7073722D7631; file digests XXH3-128 seed 0, canonical big-endian-high-first hex per theory §4.5).
- Single-threaded execution throughout c3; TT stripe locks are present and taken anyway (§5, §7).
- Every long-running run (census ply ≥ 9, spike probes) is checkpointed/resumable; runs record exact commands and outputs.
- Certificate emission is OUT of c3 (c5); RULE leaves do not exist (v1); threading is OUT (c4).
